# Toteutusmuistiinpanot

Ilmoitusmoottorin ensimmäinen versio käsittelee vain sovelluksen sisäisiä pysyviä ilmoituksia. Reaaliaikainen päivitys toimii sovelluksen ollessa auki, ja palvelin muodostaa ilmoitukset myös sovelluksen ollessa suljettu. Varsinainen käyttöjärjestelmätason push-ilmoitus lisätään erillisenä vaiheena, koska se vaatii käyttäjän luvan, push-tilauksen ja VAPID-avainten hallinnan.
