# Ilmoitusmoottorin katselmointilista

- [ ] SQL-migraatiot asentuvat tyhjään ja nykyiseen tietokantaan
- [ ] `pg_cron`-ajo syntyy nimellä `vakantti-app-notification-scan`
- [ ] RLS estää muiden käyttäjien ilmoitusten lukemisen
- [ ] admin voi tallentaa asetukset
- [ ] työnjohtaja saa vain omille alaisilleen tai vastuuprojekteilleen kuuluvat ensisijaiset hälytykset
- [ ] työntekijä saa työvuoro- ja työmääräysmuistutukset
- [ ] hyväksytty poissaolo estää kirjautumishälytyksen
- [ ] ilmoituksen avaaminen merkitsee sen luetuksi
- [ ] ratkaistu lähdetilanne poistaa ilmoituksen avoimesta listasta
- [ ] mobiilin kellovalikko mahtuu näytölle eikä aiheuta vaakavieritystä
