# Workinfo-pariteetin hyväksymislista

## A. Työmailla nyt
- [ ] Aktiivinen työaikasessio on palvelimella
- [ ] Yksi aktiivinen sessio käyttäjää kohden
- [ ] Työnjohto näkee oman käyttöoikeusalueensa henkilöt
- [ ] Admin näkee organisaation kaikki henkilöt
- [ ] Työntekijä näkee vain oman sessionsa
- [ ] Sisään- ja uloskirjaus ovat idempotentteja
- [ ] Sijainnin tarkkuus ja etäisyys tallentuvat auditointia varten
- [ ] Jatkuvaa taustaseurantaa ei käytetä

## B. Työselosteet
- [ ] Viimeisimmät selosteet dashboardilla
- [ ] Linkit tuntikirjaukseen, työmääräykseen ja projektiin
- [ ] Tyhjä, liian lyhyt ja toistuva seloste tunnistetaan
- [ ] Valmis-teksti ja avoin työmääräys tunnistetaan poikkeamaksi

## C. Raportointi
- [ ] Kuukausi- ja päivämäärärajaus
- [ ] Projekti-, henkilö-, kustannuspaikka- ja tilasuodatus
- [ ] PDF
- [ ] XLSX
- [ ] CSV
- [ ] Tulostusnäkymä
- [ ] Työaika-, palkka-, matka-, läsnäolo-, työseloste- ja alihankkijaraportit

- [ ] QR-kirjautuminen ulkopuoliselle henkilölle

## F. Laskutettavuus
