# Ilmoitusasetusten jatkokehitys

Tämä muutos laajentaa ilmoitusasetuksia rakennusalan käyttöön:

- admin tai työnjohtaja voi muuttaa työmaalle saapumisen sallittua liukumaa
- liukuman pikavalinnat kattavat nollan, minuutit ja tunnit
- työmääräyksille voidaan valita useita muistutushetkiä, kuten 14 päivää, 7 päivää, 2 päivää, 1 päivä ja määräpäivä
- jokainen valittu muistutushetki tuottaa oman deduplikoidun ilmoituksen
