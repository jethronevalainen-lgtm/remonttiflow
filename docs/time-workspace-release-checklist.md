# Työaikatyötilan julkaisulista

- [ ] Migraatio läpäisee migraatiotarkistuksen.
- [ ] Työntekijä näkee vain omat työajat, omat korjauspyynnöt ja sallitut työmääräykset.
- [ ] Työn aloittaminen muodostaa yhden aktiivisen istunnon.
- [ ] Työn vaihtaminen päättää edellisen istunnon automaattisesti.
- [ ] Työn lopettaminen muodostaa yhden tuntikirjauksen ja päättää sijaintileimauksen ilman toista tuntiriviä.
- [ ] Manuaalinen kirjaus laskee tunnit alku- ja loppuajasta.
- [ ] Työnjohtaja ja järjestelmänvalvoja näkevät kaikki työajat ja aktiiviset työntekijät.
- [ ] Työnjohtaja voi hyväksyä päivän ja pyytää korjausta.
- [ ] Työnjohtaja ei voi muuttaa organisaation työaikasääntöjä.
- [ ] Projektikoordinaattori näkee vain omien projektiensa työajat eikä saa muokkaustoimintoja.
- [ ] Tilaajalla ei ole reittiä työaikatyötilaan.
- [ ] Lukittua palkkakauden kirjausta ei voi muuttaa tavallisesta näkymästä.
- [ ] Reaaliaikaiset päivitykset toimivat tuntikirjauksille, istunnoille, sijaintileimauksille ja korjauspyynnöille.
- [ ] TypeScript, lint, testit, build, autentikoitu moniroolitesti ja mobiilitesti läpäisevät.
